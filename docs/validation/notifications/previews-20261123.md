## Expected limits

Network/key unavailability keeps event-specific safe copy and allows bounded retries.
Existing category defaults, quiet activity, chat mute and the 30-second sound budget
remain. Android permission, channel, lock-screen, battery and DND settings still apply.
The tray is not an exhaustive history; existing provider collapse/expiry policies
remain. Already displayed private content cannot be recalled after a later remote
change without a subsequent device update. Local reminders use the last authorized
sync while offline, with details in protected storage. See the notification flow
and backend rollout guide for the schema-2 capability and deployment order.
