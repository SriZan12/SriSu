## Behavior

Home bell → Notifications. Includes all 22 non-chat activity policies in 30-day
history, with account-wide unread counts and read state. Chat, receipts, typing,
local reminders and diagnostics are excluded. All/Unread, Today/Yesterday/Earlier,
mark-all-read, refresh, settings and load-earlier actions are available. Domain
metadata remains content-free; readable copy comes from the currently authorized
resource. No private answers are exposed. Blocked/former-couple events disappear;
deleted/expired content has safe unavailable copy. Opens reauthorize before typed
navigation. Background/logout clears list memory and fences late responses.

Event capture is now independent of push enablement and category preferences;
those preferences still govern phone alerts. Existing captured events become
unread history. No uncaptured backfill or replayed push was added. Backend-first
migration `notifications.0006_notification_inbox` adds a nullable read timestamp
and recipient/time/UUID index. Old clients remain compatible.
