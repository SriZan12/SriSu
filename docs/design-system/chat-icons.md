# Chat icon assets

The chat UI uses existing Material core icons and a local subset of Google's
outlined Material icons, shared across Android and iOS. The Android extended
icon library is not a dependency of the new shared controls. No dependency was
added. SVG path geometry is preserved in 24 × 24 Android vector XML; the two
Spark polygons are converted to equivalent closed paths. Tint comes from the
SriSu theme at the call site. Reply is mirrored for RTL.

Source: https://github.com/google/material-design-icons (read 2026-10-10).
